About VisionVoice

VisionVoice is an AI-based voice assistance project. It uses camera-based object detection and speech output to help users understand some objects in their surroundings.

Project Aim

To develop a simple application combining computer vision and voice technology.

Technologies Used

HTML, CSS, JavaScript, TensorFlow.js, COCO-SSD, Web Speech API and Geolocation API.

Location Sharing

The location feature uses browser GPS permission to create a Google Maps link that the user can share.

How to Use VisionVoice

1. Create an Account

Enter your name, email and password. All fields are compulsory.

2. Sign In

Use your registered email and password.

3. Start Camera

Choose the front or rear camera and allow browser camera permission.

4. Detect Objects

Point your camera towards supported everyday objects.

5. Listen

Enable automatic announcements or press Describe Scene.

6. Share Location

Press Get My Location, then Share Location. Choose a contact in your sharing menu or use the WhatsApp option if available.

7. Sign Out

Stop the camera and sign out when finished.
